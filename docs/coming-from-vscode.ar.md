إيديكم عارفة الحاجات فين من الأول. الصفحة دي بتربط العادات دي بـ NMOX Studio: الاختصارات الأول، وبعدين كل فكرة من VS Code موجودة فين هنا، وفي الآخر إيه اللي مختلف بجد.

أول أربع اختصارات مستخدم VS Code بيدوس عليهم بيعملوا اللي هو مستنيه: **⇧⌘P** بيفتح لوحة الأوامر، و**⇧⌘E** شجرة الملفات، و**⇧⌘X** الإضافات، و**⌃\`** الترمينال. متسجّلين في البروفايلات الخمسة بتاعة اختصارات لوحة المفاتيح اللي المنصة جاية بيها، وفيه بوابة في البناء بتفك كل واحد منهم من خلال اختصارات لوحة المفاتيح المتجمّعة على macOS وWindows وLinux، عشان مفيش حاجة تانية تشتغل مكانه.

<a id="the-chords"></a>
## الاختصارات

أعمدة macOS بتستخدم رموز شريط القوايم (⌃ Control، ‏⌥ Option، ‏⇧ Shift، ‏⌘ Command)؛ وأعمدة Windows وLinux هي نفس الاختصار على كيبورد PC.

| عايزين | VS Code، ‏macOS | NMOX، ‏macOS | VS Code، ‏Win/Linux | NMOX، ‏Win/Linux |
|---|---|---|---|---|
| لوحة الأوامر | ⇧⌘P | **⇧⌘P** (أو ⌘I) — البحث السريع | Ctrl+Shift+P | **Ctrl+Shift+P** (أو Ctrl+I) |

كل اختصار NMOX في الجدول اتقرا من اختصارات لوحة المفاتيح اللي اتشحنت، مش من الذاكرة (‏⌘, بتاع قايمة التطبيق نفسها على macOS). شوية حاجات الجدول مايقدرش يقولها في خانة:

- **F5 محجوز وقت التصحيح.** هنا معناه *Continue*، زي أي IDE من عيلة NetBeans، فتشغيل التصحيح بيبدأ من **⇧⌘F5** ‏(Ctrl+Shift+F5) وبيكمّل من F5.
- **⌃R هو تغيير الاسم هنا**، وعشان كده *تبديل المشروع* قاعد على ⌥⌘P بدل اختصار Open Recent بتاع VS Code. تغيير الاسم بيشتغل لما اللغة اللي ورا الملف تدعمه.
- **Ctrl+, على Windows وLinux** بيرجع لورا في تاريخ التعديلات، زي ما طول عمره في NetBeans؛ والإعدادات موجودة تحت أدوات ◂ الخيارات (على macOS، ‏**Settings…** في قايمة التطبيق، ⌘,).

**مساعدة ◂ اختصارات الكيبورد…** بتعرض كل اختصار NMOX في بروفايل اختصارات لوحة المفاتيح الشغال عندكم، ومنهم اختصارات VS Code الأربعة، ومقروية من اختصارات لوحة المفاتيح الشغالة، فمايقدرش يبعد عن اللي الزراير بتعمله.

### كل اختصار تعديل، متقاس

الاختصارات اللي إيديكم الجاية من VS Code بتدوّر عليها وانتوا بتعدّلوا، وكل واحد فيها اتشاف في اختصارات لوحة المفاتيح اللي بتتشحن مع البروفايل الافتراضي على macOS. لو اختصار VS Code كان فاضي هنا، فهو دلوقتي بيعمل اللي VS Code بيعمله (الصفوف اللي مكتوب فيها **نفس الحاجة:**)؛ ولو كان ليه معنى مستخدمين NetBeans معتمدين عليه، بيفضل على معناه، والصف بيقول فين الأمر بتاع VS Code.

الاختصارات المعلّمة بـ **نفس الحاجة:** متسجّلة في كل بروفايل اختصارات بيسيبها فاضية، والبروفايل اللي بيدّي واحد منها معنى خاص بيه بيحتفظ بالمعنى ده: F12 في بروفايلات Eclipse وEmacs وNetBeans 5.5، وF2 في كل البروفايلات ما عدا الافتراضي، و⇧F12 في Emacs وNetBeans 5.5، و⌃- و⌃⇧- في Emacs وIntelliJ، و⇧⌥F في IntelliJ. على Windows وLinux، F12 و⇧F12 وF2 بيشتغلوا بنفس الطريقة؛ باقي اختصارات VS Code هناك مختلفة، والجدول اللي فوق فيه الاتنين.

## من الترمينال

`code .`‎ هو `nmox .`:

```bash
cd ~/code/my-app
nmox .          # open this folder (manifest or not) and aim the IDE at it
nmox src/app.ts # open one file
nmox src/app.ts:42  # open it at line 42 (code -g's form; -g itself is accepted)
nmox            # just start the IDE
```

الأمر بيرجع على طول، و`nmox` تاني بيسلّم المجلد بتاعه للـ IDE اللي شغال بالفعل. العمود كمان (`src/app.ts:42:7`) مقبول، والمحرر بيفتح في أول السطر؛ والاسم اللي مش موجود بيترفض في التيرمينال بدل ما يشغّل أي حاجة. الـ ‎`-r` بتاع VS Code مقبول، و‎`-n` بيفتح في النافذة الوحيدة؛ و‎`-a` و‎`-v` بيترفضوا برسالة بتذكر اسمهم.

الـ ‎`-w` (`--wait`) بيفتح ملف ويستنى لحد ما تقفلوا التبويب بتاعه، والـ ‎`-d` (`--diff`) بيقارن بين ملفين جنب بعض، فـ NMOX Studio يقدر يبقى المحرر والـ difftool والـ mergetool بتوع git، زي ما `code --wait` بيعمل:

```bash
git config --global core.editor "nmox -w"
git config --global diff.tool nmox
git config --global difftool.nmox.cmd 'nmox -w -d "$LOCAL" "$REMOTE"'
git config --global merge.tool nmox
git config --global mergetool.nmox.cmd 'nmox -w "$MERGED"'
git config --global mergetool.nmox.trustExitCode false
```

بعدها `git commit` بيفتح الرسالة في الـ IDE؛ احفظوها واقفلوا التبويب، وgit يكمّل. ولو قفلتوا الـ IDE والملف لسه مفتوح، برضه بيرجع، باللي اتحفظ منه. وبنفس الطريقة، الأمر `git mergetool` بيفتح كل ملف فيه تعارض. في المكان اللي VS Code بيحط فيه *Accept Current Change | Accept Incoming Change | Accept Both Changes* فوق التعارض، NMOX Studio بيلوّن الجانبين وبيحط تحذير على السطر ‎`<<<<<<<`‎؛ اللمبة اللي في الهامش، أو الإصلاح السريع والمؤشر على السطر ده (⌘. على Mac، وAlt+Enter في غيره)، بيعرضوا نفس الاختيارات التلاتة، كل واحد فيهم تعديل واحد ينفع يترجع. احفظوا، واقفلوا التبويب، وgit ينقل للملف اللي بعده. الألوان والاختيارات التلاتة موجودين في أي ملف فيه علامات تعارض، بـ `git mergetool` أو من غيره. **الفريق ◂ استخدام NMOX Studio مع Git…** بيضبط لكم نفس السطور دي، بعد ما يوريكم كل واحد فيهم متظبط على إيه دلوقتي. Homebrew، والـ installer بتاع Windows (*إضافة «nmox» لـ PATH*)، وحزم Linux بيحطوه على الـ PATH بتاعكم؛ ولو ثبّتوا من الـ DMG، [دليل المستخدم](user-guide.ar.md#2-first-launch) بيوريكم الرابط في سطر واحد.

## كل فكرة من VS Code موجودة فين

| في VS Code | في NMOX Studio |
|---|---|
| **Explorer** | **استوديو المشاريع** (⇧⌘E) — شجرة الملفات (كليك يمين على ملف: نسخ المسار، ونسخ المسار النسبي، وعرض في Finder)، والقوالب، ومحرر `package.json` بتاع المشروع. **منضدة العمل** (⌥⌘0) هي القاعدة الأساسية: الملفات المفتوحة، والملفات الأخيرة، والمشاريع الأخيرة، وكل حاجة شغالة. |
| **Command Palette** | **البحث السريع** (⇧⌘P أو ⌘I) — الأوامر، والملفات، والمشاريع الأخيرة، وأجهزة الراك، والخوادم الشغّالة، وطلبات استوديو الـ API، والرموز. وأسامي أوامر VS Code نفسه بتشتغل كمان: *Format Document*، و*Toggle Terminal*، و*Git: Commit*، أو *Open Settings* بتعرض الأمر اللي بيعمل نفس الحاجة هنا، تحت **أوامر VS Code**، باسمه واختصاره هو. |
| **Extensions** | **أدوات ◂ الإضافات** بتثبّت الموديولات وبتحدّثها، ومنها تحديثات NMOX نفسه. كتير من اللي الإضافة بتضيفه في VS Code هو هنا **جهاز في الراك** — وتقدروا تكتبوا واحد كملف JSON في ‎`~/.nmox/devices.d` ‏([ملفات الأجهزة](device-files.md)). |
| **`tasks.json`** | ملف ‎`.vscode/tasks.json` بتاع المستودع بتاعكم بيتقري: اكتبوا اسم مهمة في البحث السريع (⇧⌘P أو ⌘I)، وEnter على *تشغيل مهمة: ⁦build⁩ — ⁦make all⁩* بيشغّلها، والثقة في مساحة العمل بتسأل الأول في مشروع لسه ماوثقتوش فيه، والناتج بيظهر في نافذة Output، وزرار ■ في شريط الأدوات بيوقفها. وجنبه، السكريبتات بتاعة المشروع نفسه بتشتغل زي ما هي مكتوبة: التشغيل / البناء / الاختبار في شريط الأدوات (F6، F11، ‏⌃F6)، و**تشغيل سكريبت** على سطر في قسم scripts في `package.json`، و**مستكشف NPM**، و**راك المهام** (⌘9)، اللي المهام فيه أجهزة بتوصّلوها ببعض. |
| **`launch.json`** | ملف ‎`.vscode/launch.json` بتاع المستودع بتاعكم بيتقري: اكتبوا اسم إعداد في البحث السريع (⇧⌘P أو ⌘I)، وEnter على *تصحيح: ⁦Launch Program⁩ — ⁦${workspaceFolder}/server.js⁩* بيشغّل مصحح الأخطاء بنقاط التوقف على البرنامج ده، والثقة في مساحة العمل بتسأل الأول. إعدادات Node ‏(`node`، `pwa-node`) وPython ‏(`python`، `debugpy`) بتصحح الـ `program` بتاعها في الـ `cwd` بتاعها، مع الـ `args` والـ `env` بتوعها؛ وإعدادات Chrome ‏(`chrome`، `pwa-chrome`) بتفتح الـ `url` بتاعها (أو الـ `file`) مع الـ `webRoot` بتاعها. ومن غير `launch.json`، **تصحيح الملف** (⇧⌘F5) وزرار التصحيح في شريط الأدوات بيعرفوا يشغّلوا إيه من المشروع نفسه — نقطة الدخول بتاعة سكريبت `start`، و`main`، و`index.js` — وجهاز الراك **INSPECTOR** بيشغّل مصحّح كخطوة في خط. |
| **Integrated terminal** | نافذة **الترمينال** (⌃\`): أول ضغطة بتشغّل shell في مجلد المشروع، والضغطات اللي بعدها بترجّعه. |
| **`settings.json`** | أدوات ◂ الخيارات (على macOS، ‏NMOX Studio ‏◂‏ Settings…). ملف ‎`.vscode/settings.json` بتاع المستودع بيتقري هو كمان: `editor.tabSize` و`editor.insertSpaces` و`editor.indentSize` بيحددوا المسافة البادئة لملفاته وأنتم بتكتبوا، و`files.trimTrailingWhitespace` و`files.insertFinalNewline` (لما يكونوا `true`) بيتطبقوا وقت الحفظ، وبلوك لغة زي ‎`"[typescript]"` بيغطّي عليهم في اللغة بتاعته. ولو المستودع فيه كمان ملف ‎`.editorconfig`، ملف ‎`.editorconfig` هو اللي بيكسب في أي حتة الاتنين بيقولوا فيها حاجة. |
| **Problems panel** | **بنود العمل** (⌘6)، أو دوسوا على عدّاد **⁦✕ ⚠⁩** في شريط الحالة: أخطاء وتحذيرات خوادم اللغة، ونتايج الـ lint والأنواع من أجهزة الراك PURITY وTYPEGUARD. زي VS Code، بعض الخوادم بتبلّغ بس عن الملفات اللي فاتحينها؛ وgopls بيبلّغ عن الحزمة كلها. |
| **Outline** | **لوحة التنقل** (⌘7). |
| **Source Control** | علامة الـ git في شريط الحالة (الفرع والتغييرات، وضغطة واحدة للتاريخ) وقايمة **الفريق**. |
| **Workspace Trust** | نفس الفكرة، ومتطبّقة قبل ما أي حاجة المستودع اختارها تشتغل: فتح مشروع متنسخ من برّه مش بيشغّل أي حاجة لحد ما توثقوا فيه. |
| **Keyboard Shortcuts editor** | أدوات ◂ الخيارات ◂ اختصارات لوحة المفاتيح (على macOS، ‏Settings… ◂ اختصارات لوحة المفاتيح) — عدّلوا أي اختصار، أو بدّلوا البروفايل كله لـ Eclipse أو Emacs أو IntelliJ. |

أول مرة تفتحوا فيها مستودع فيه ‎`.vscode/tasks.json` أو `launch.json` أو `settings.json`، بيظهر إشعار بيقول لقى إيه ومكانه فين؛ دوسوا عليه عشان يفتح البحث السريع. وبيقول كده مرة واحدة بس لكل مشروع.

<a id="what-is-honestly-different"></a>
## إيه اللي مختلف بجد

- **⌘D بيضيف التكرار الجاي في اختصارات لوحة المفاتيح الافتراضية، مش في كل بروفايل.** بروفايل Eclipse بيسيب ⌘D على *Delete Line* بتاع Eclipse، وبروفايل NetBeans 5.5 على *Shift Line Left*، وبروفايل Emacs على *kill word* (وCtrl+D على *delete character* على Windows وLinux)؛ وبروفايل IntelliJ فيه ⌘D على macOS وبيسيب Ctrl+D على *Duplicate Line* على Windows وLinux. والاختصار التاني للحركة دي كمان بيختلف حسب البروفايل: ⌘J ‏(Ctrl+J) في الافتراضي، و⌃J ‏(Alt+J) في Eclipse وIntelliJ، ومفيش في Emacs وNetBeans 5.5، وهناك تقدروا تدّوله واحد من اختصارات لوحة المفاتيح.
- **⌃\` بيفتح الترمينال وبينقل له التركيز؛ مش بيخبّيه.** ولما التركيز يبقى في الترمينال، الزراير بتبقى بتاعة الـ shell، فالضغطة التانية بتروح للـ shell مش بترجّعكم للمحرر.
- **`launch.json` بيتقري، واللي مصحح الأخطاء مايقدرش يلتزم بيه بيترفض.** مصحح الأخطاء هنا بيوصّل برنامج، ومجلد الشغل بتاعه، والـ `args` بتاعته (قايمة نصوص) والـ `env` بتاعته (نصوص بتتضاف على البيئة الموروثة)، فالإعداد اللي بيحدد `envFile` أو `runtimeExecutable` أو `runtimeArgs` أو `preLaunchTask` أو أي حقل تاني ماتعلّمهوش بيظهر في القايمة بس مابيشتغلش: Enter بيقول أسامي الحقول في شريط الحالة. تشغيل البرنامج من غيرهم كان هيصحح حاجة غير اللي مكتوب في الملف. والـ `args` المكتوبة كنص واحد (VS Code بيسلّمه لـ shell) وقيمة `null` في الـ `env` (ودي بتلغي متغير) بيترفضوا بنفس الطريقة، وكمان ‎`"request": "attach"`، وأي عنصر في `compounds`، ونوع مالوش محوّل هنا (`go`، `msedge`، `cppdbg` والباقي)، وقيمة VS Code بس اللي يقدر يوفّرها (`${file}`، `${input:…}`)، ومسار برّه المشروع. الحقول اللي بتشكّل بس اللي مصحح الأخطاء بيعرضه — `skipFiles`، `outFiles`، `sourceMaps`، `console`، `justMyCode`، `presentation` — بتتقبل ومابتتطبقش؛ وناتج البرنامج بيروح لنافذة Output.
- **`tasks.json` بيتقري، واللي مايقدرش يشتغل زي ما هو مكتوب بيترفض.** المهمة اللي بتستخدم قيمة VS Code بس اللي يقدر يوفّرها (`${input:…}`، `${file}`، `${config:…}`، `${command:…}`) أو اللي فيها `dependsOn` لمهمة تانية بتظهر في القايمة بس مابتشتغلش: Enter بيقول أنهي متغير أو أنهي مهمة في شريط الحالة. تشغيلها والقيمة فاضية، أو من غير المهمة اللي معتمدة عليها، كان هيشغّل حاجة غير اللي مكتوب في الملف. ونفس الكلام على نوع مهمة بيوفّره امتداد (`gulp`، `typescript`)، وعلى مجلد شغل برّه المشروع.
- **مهمة `"type": "shell"` بتشتغل في الـ shell اللي VS Code كان هيستخدمه.** على macOS وLinux ده الـ `$SHELL` بتاعكم مع `-c` (الـ zsh أو bash أو fish على macOS بيبدأ كـ login shell، `-l`، زي البروفايلات الافتراضية بتاعة VS Code)؛ وعلى Windows هو PowerShell، و`pwsh` لو متثبّت. و`options.shell` بيتحترم بطريقة VS Code: حددوا `executable` والمهمة هتشتغل بالظبط بالـ `args` اللي تدوها لها، فالـ bash محتاج `"args": ["-c"]`. على Windows مفيش غير PowerShell (الـ args بتخلص بـ `-Command`) و`cmd.exe` (الـ args بتخلص بـ ‎`/c`) اللي بيشتغلوا؛ وأي shell تاني هناك بيترفض بالاسم بدل ما ياخد سطر أوامر متظبط بالتخمين.
- **مفيش بروفايل اختصارات اسمه «VS Code».** الاختصارات اللي فوق موجودة في البروفايل الافتراضي والأربعة التانيين. فيه استثناء واحد مقصود: في بروفايل **Eclipse**، ‏⇧⌘E بيفضل *Switch to Editor* بتاع Eclipse نفسه، وجوّه المحرر ⇧⌘P و⇧⌘X بيفضلوا بمعانيهم في Eclipse (القوس المقابل، والحروف الكبيرة) — اللي اختار Eclipse مستني Eclipse.
- **على Linux، ‏Ctrl+\` بيفتح الترمينال، مش مبدّل نوافذ.** المبدّل على Ctrl+Tab. وعلى سطح مكتب بياخد Ctrl+Tab لنفسه (KDE مثلًا)، **نافذة ◂ المستندات…** بتعرض الملفات المفتوحة بداله.
- **اختصارات Ctrl+Alt ممكن تتخانق مع AltGr.** على Windows، ترتيبات الكيبورد اللي بتكتب حروف بـ AltGr (البولندي مثلًا) بتبعت Ctrl+Alt بداله. لو Ctrl+Alt+P أو Ctrl+Alt+K بيكتبوا لكم حرف، انقلوا *تبديل المشروع* أو اختصارات التجارب من اختصارات لوحة المفاتيح.
- **إضافات VS Code مش بتتثبت هنا.** ذكاء اللغات بييجي من خوادم اللغات اللي NMOX عارفها (طبيب البيئة بيعرض الناقص وإزاي تثبّتوه)، ومن قواعد اللغات بتاعة المحرر نفسه، ومن الإضافات المعمولة لمنصة NetBeans.
