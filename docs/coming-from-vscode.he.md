הידיים שלכם כבר יודעות איפה הדברים נמצאים. העמוד הזה ממפה את ההרגלים האלה אל NMOX Studio: קודם הקיצורים, אחר כך איפה כל רעיון של VS Code נמצא כאן, ובסוף מה באמת שונה.

ארבעת הקיצורים הראשונים שמשתמש VS Code לוחץ עליהם עושים את מה שהוא מצפה: **⇧⌘P** פותח את לוח הפקודות, **⇧⌘E** את עץ הקבצים, **⇧⌘X** את התוספים, ו‑**⌃\`** את המסוף. הם רשומים בכל חמשת פרופילי מיפוי המקשים שהפלטפורמה מביאה, ושער בבנייה מפענח כל אחד מהם דרך מיפוי המקשים המורכב ב‑macOS, ב‑Windows וב‑Linux, כדי ששום דבר אחר לא יופעל במקומו.

<a id="the-chords"></a>
## הקיצורים

עמודות macOS משתמשות בסמלים של שורת התפריטים (⌃ Control, ‏⌥ Option, ‏⇧ Shift, ‏⌘ Command); העמודות של Windows ו‑Linux הן אותו קיצור במקלדת של PC.

| מה אתם רוצים | VS Code, ‏macOS | NMOX, ‏macOS | VS Code, ‏Win/Linux | NMOX, ‏Win/Linux |
|---|---|---|---|---|
| לוח הפקודות | ⇧⌘P | **⇧⌘P** (או ⌘I) — חיפוש מהיר | Ctrl+Shift+P | **Ctrl+Shift+P** (או Ctrl+I) |
| פתיחת קובץ לפי שם | ⌘P | **⌘P** — מעבר לקובץ | Ctrl+P | **Ctrl+P** |
| עץ הקבצים | ⇧⌘E | **⇧⌘E** — אולפן הפרויקטים | Ctrl+Shift+E | **Ctrl+Shift+E** |
| הרחבות | ⇧⌘X | **⇧⌘X** — כלים ◂ תוספים | Ctrl+Shift+X | **Ctrl+Shift+X** |
| המסוף, בתיקיית הפרויקט | ⌃\` | **⌃\`** | Ctrl+\` | **Ctrl+\`** |
| פתיחת פרויקט אחרון | ⌃R | **⌥⌘P** — החלפת פרויקט… | Ctrl+R | **Ctrl+Alt+P** |
| מעבר לסמל בפרויקט | ⌘T | **⌥⇧⌘O** | Ctrl+T | **Ctrl+Alt+Shift+O** |
| מעבר להגדרה | F12 | **⌘B** | F12 | **Ctrl+B** |
| שינוי שם של סמל | F2 | **⌃R** | F2 | **Ctrl+R** |
| מעבר לשורה | ⌃G | **⌃G** | Ctrl+G | **Ctrl+G** |
| הערה על שורה והסרתה | ⌘/ | **⌘/** | Ctrl+/ | **Ctrl+/** |
| הצגת הצעות | ⌃Space | **⌃Space** | Ctrl+Space | **Ctrl+Space** |
| הוספת המופע הבא לבחירה | ⌘D | **⌘J** | Ctrl+D | **Ctrl+J** |
| בחירת כל המופעים | ⇧⌘L | **⌃⇧⌘J** | Ctrl+Shift+L | **Ctrl+Alt+Shift+J** |
| הוספת סמן מעל / מתחת | ⌥⌘↑ / ⌥⌘↓ | **⌥⌘↑ / ⌥⌘↓** | Ctrl+Alt+↑ / ↓ | **Alt+Shift+[ / ]** |
| הזזת השורה למעלה / למטה | ⌥↑ / ⌥↓ | **⌃⇧↑ / ⌃⇧↓** | Alt+↑ / ↓ | **Alt+Shift+↑ / ↓** |
| שכפול השורה למטה | ⇧⌥↓ | **⌥⇧↓** | Shift+Alt+↓ | **Ctrl+Shift+↓** |
| מחיקת השורה | ⇧⌘K | **⌘E** | Ctrl+Shift+K | **Ctrl+E** |
| עיצוב המסמך | ⇧⌥F | **⌃⇧F** | Shift+Alt+F | **Alt+Shift+F** |
| סגירת לשונית העורך | ⌘W | **⌘W** | Ctrl+W | **Ctrl+W** |
| חלונית הבעיות | ⇧⌘M | **⌘6** — פריטי פעולה (כאן ⇧⌘M מוסיף ומסיר סימנייה) | Ctrl+Shift+M | **Ctrl+6** |
| הוספת נקודת עצירה והסרתה | F9 | **⌘F8** | F9 | **Ctrl+F8** |
| התחלת ניפוי | F5 | **⇧⌘F5** — ניפוי הקובץ | F5 | **Ctrl+Shift+F5** |
| הרצה בלי ניפוי | ⌃F5 | **F6** — הרצת הפרויקט | Ctrl+F5 | **F6** |
| הגדרות | ⌘, | **⌘,** — NMOX Studio ‏◂‏ Settings… | Ctrl+, | כלים ◂ אפשרויות (בלי קיצור) |

כל קיצור של NMOX בטבלה נקרא מתוך מיפוי המקשים שנשלח, לא מהזיכרון (‏⌘, שייך לתפריט האפליקציה של macOS). כמה דברים שהטבלה לא יכולה לומר בתא אחד:

- **F5 תפוס בזמן ניפוי.** כאן הוא אומר *Continue*, כמו בכל IDE ממשפחת NetBeans, ולכן הרצת ניפוי מתחילה מ‑**⇧⌘F5** ‏(Ctrl+Shift+F5) וממשיכה מ‑F5.
- **⌃R הוא שינוי שם כאן**, ולכן *החלפת פרויקט* יושבת על ⌥⌘P ולא על הקיצור של Open Recent ב‑VS Code. שינוי השם עובד כשהשפה שמאחורי הקובץ תומכת בו.
- **Ctrl+, ב‑Windows וב‑Linux** חוזר אחורה בהיסטוריית העריכה, כמו שתמיד היה ב‑NetBeans; ההגדרות נמצאות תחת כלים ◂ אפשרויות (ב‑macOS, ‏**Settings…** בתפריט האפליקציה, ⌘,).

**עזרה ◂ קיצורי מקלדת…** מונה כל קיצור של NMOX בפרופיל מיפוי המקשים הפעיל שלכם, כולל ארבעת הקיצורים של VS Code, כפי שהם נקראים ממיפוי המקשים שרץ, כך שהרשימה לא יכולה לסטות ממה שהמקשים עושים.

<a id="from-the-terminal"></a>
## מהמסוף

`code .` הוא `nmox .`:

```bash
cd ~/code/my-app
nmox .          # open this folder (manifest or not) and aim the IDE at it
nmox src/app.ts # open one file
nmox            # just start the IDE
```

הפקודה חוזרת מיד, ו‑`nmox` שני מעביר את התיקייה שלו ל‑IDE שכבר רץ. Homebrew, מתקין Windows (*הוספת "nmox" ל-PATH*) וחבילות Linux מכניסים אותה ל‑PATH שלכם; להתקנה מה‑DMG, [המדריך למשתמש](user-guide.he.md#2-first-launch) מראה את הקישור בשורה אחת.

<a id="where-each-vs-code-idea-lives"></a>
## איפה נמצא כל רעיון של VS Code

| ב‑VS Code | ב‑NMOX Studio |
|---|---|
| **Explorer** | **אולפן הפרויקטים** (⇧⌘E) — עץ הקבצים, התבניות ועורך ה‑`package.json` של הפרויקט. **שולחן העבודה** (⌥⌘0) הוא הבסיס: קבצים פתוחים, קבצים אחרונים, פרויקטים אחרונים וכל מה שרץ. |
| **Command Palette** | **חיפוש מהיר** (⇧⌘P או ⌘I) — פעולות, קבצים, פרויקטים אחרונים, מכשירים בראק, שרתים חיים, בקשות של אולפן ה‑API, סמלים. |
| **Extensions** | **כלים ◂ תוספים** מתקין ומעדכן מודולים, כולל העדכונים של NMOX עצמו. הרבה ממה שהרחבה מוסיפה ב‑VS Code הוא כאן **מכשיר בראק** — ואפשר לכתוב אחד כקובץ JSON בתיקייה `~/.nmox/devices.d` ‏([קובצי מכשירים](device-files.md)). |
| **`tasks.json`** | הסקריפטים של הפרויקט עצמו, שרצים כפי שנכתבו: הרצה / בנייה / בדיקה בסרגל הכלים (F6, ‏F11, ‏⌃F6), **הרצת סקריפט** על שורה בקטע ה‑scripts של `package.json`, **סייר NPM**, ו**ראק המשימות** (⌘9), שבו משימות הן מכשירים שמחווטים יחד. |
| **`launch.json`** | **ניפוי הקובץ** (⇧⌘F5) ולחצן הניפוי בסרגל הכלים מבינים מה להפעיל מתוך הפרויקט עצמו — נקודת הכניסה של הסקריפט `start`, ‏`main`, ‏`index.js` — ומכשיר הראק **INSPECTOR** מפעיל מנפה כשלב בצינור. |
| **Integrated terminal** | החלון **מסוף** (⌃\`): הלחיצה הראשונה מפעילה shell בתיקיית הפרויקט, ולחיצות אחר כך מחזירות אותו. |
| **`settings.json`** | כלים ◂ אפשרויות (ב‑macOS, ‏NMOX Studio ‏◂‏ Settings…). קובץ ה‑`.editorconfig` של הפרויקט שלכם מכובד בשמירה. |
| **Problems panel** | **פריטי פעולה** (⌘6): ממצאי lint וטיפוסים ממכשירי הראק PURITY ו‑TYPEGUARD, לצד הקווים הגליים בעורך. |
| **Outline** | ה**נווט** (⌘7). |
| **Source Control** | סימן ה‑git בשורת המצב (ענף ושינויים, לחיצה אחת להיסטוריה) והתפריט **צוות**. |
| **Workspace Trust** | אותו רעיון, שנאכף לפני שמשהו שמאגר בחר רץ: פתיחת פרויקט משוכפל לא מריצה דבר עד שאתם נותנים בו אמון. |
| **Keyboard Shortcuts editor** | כלים ◂ אפשרויות ◂ מיפוי מקשים (ב‑macOS, ‏Settings… ◂ מיפוי מקשים) — עריכת כל קיצור, או החלפת הפרופיל כולו ל‑Eclipse, ‏Emacs או IntelliJ. |

<a id="what-is-honestly-different"></a>
## מה באמת שונה

- **⌘D הוא לא סמנים מרובים כאן.** אותה פעולה היא **⌘J** ‏(Ctrl+J); ‏⌘D עצמו לא מוקצה. אם האצבעות שלכם מתעקשות, הקצו אותו מחדש תחת מיפוי מקשים.
- **⌃\` פותח את המסוף ומעביר אליו את המיקוד; הוא לא מסתיר אותו.** וכשהמיקוד במסוף, המקשים שייכים ל‑shell שלכם, ולכן הלחיצה השנייה מגיעה ל‑shell ולא מחזירה אתכם לעורך.
- **`.vscode/tasks.json` ו‑`launch.json` לא נקראים.** משימה היא פקודה שמאגר בחר, וקריאה שלה ראויה לתכנון משלה סביב אמון בסביבת העבודה; עד אז, הסקריפטים של הפרויקט עצמו וכללי נקודת הכניסה לניפוי שלמעלה עושים את העבודה הזו.
- **אין פרופיל מיפוי מקשים בשם "VS Code".** הקיצורים שלמעלה נמצאים בפרופיל ברירת המחדל ובארבעת האחרים. חריג אחד מכוון: בפרופיל **Eclipse**, ‏⇧⌘E נשאר ה‑*Switch to Editor* של Eclipse עצמו, ובתוך העורך ⇧⌘P ו‑⇧⌘X שומרים על המשמעות שלהם ב‑Eclipse (סוגר תואם, אותיות רישיות) — מי שבחר ב‑Eclipse מצפה ל‑Eclipse.
- **ב‑Linux, ‏Ctrl+\` פתח פעם את מחליף החלונות** — הגיבוי של הפלטפורמה לשולחנות עבודה (KDE) שתופסים את Ctrl+Tab. עכשיו הוא פותח את המסוף; המחליף עדיין על Ctrl+Tab.
- **קיצורי Ctrl+Alt יכולים להתנגש ב‑AltGr.** ב‑Windows, פריסות מקלדת שמקלידות תווים עם AltGr (פולנית, למשל) שולחות בשבילו Ctrl+Alt. אם Ctrl+Alt+P או Ctrl+Alt+K מקלידים לכם תו, העבירו את *החלפת פרויקט* או את קיצורי הניסויים תחת מיפוי מקשים.
- **הרחבות של VS Code לא מותקנות כאן.** האינטליגנציה לשפות מגיעה משרתי השפה ש‑NMOX מכיר (אבחון הסביבה מונה מה חסר ואיך להתקין אותו), מהדקדוקים של העורך עצמו, ומתוספים שנבנו לפלטפורמת NetBeans.
