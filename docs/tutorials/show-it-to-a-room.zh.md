有些日子，要交付的不是代码，而是*展示*：投影仪、README、议题评论、幻灯片。NMOX Studio 为这样的人准备了一小套演示工具，而且每一件都建立在 IDE 原本就有的东西上，而不是外挂上去的：编辑器自己的文字缩放、给代码围栏命名的那一套统一的语言词汇、文档截图工具自己的绘制。本教程一次走完全部，从最后一排一直到剪贴板。

## 开始之前

打开一个放在 GitHub 仓库里的项目（带链接的操作需要一个指向 GitHub 的 `origin` — 其他情况都会被明确拒绝，而不是去猜），再打开它的一个源文件。先保存：带链接的操作同样会拒绝有未保存改动的缓冲区，因为与链接对不上的代码块就是一个谎言。为了第 2 步，也把项目跑起来（工具栏的 ▶ 或者机架），让内置浏览器里有页面、Output 窗口里有输出。

## 步骤

1. **让全屋都看得清。**`视图 ▸ 演示模式`。每个打开的编辑器都会实时放大十个点，模式开启期间新打开的编辑器也一样。菜单项会显示勾选，状态栏会说明放大了多少。你的设置里什么都不会写入 — 关掉它（或者重启），字体就完全恢复原样，包括你额外用 ⌥ 加滚轮做过的微调。

2. **看着 IDE 的其余部分跟上。**模式开启时，内置浏览器里的页面会缩放到你原有缩放比例的 150%，Output 窗口的文字放大同样的十个点，每个打开的终端也一起放大 — 离开时各自恢复到自己原来的大小。演示正在运行的应用、它的输出，以及你在其中输入的 shell，最后一排都看得清，而不只是代码。

3. **让大家看到你的手。**`视图 ▸ 显示按键`，然后按 `⌘S`。窗口底部会大大地出现一块写着 `⌘S` 的深色胶囊，停留片刻（重复按下会显示 `⌘Z ×3`）。现在打一个词：什么都不会出现。只有带 ⌘、⌃ 或 ⌥ 的组合键，以及功能键和 Escape 才会显示 — 普通输入永远不会，所以在终端里输入的密码不会跑到投影仪上。

4. **分享代码。**选中几行，选择 `编辑 ▸ 复制为 Markdown`（或者在编辑器里右键）。粘贴到 README、议题或聊天里：得到的是一个标注了该文件语言的围栏代码块（` ```html `、` ```typescript `、` ```bash `…），结尾恰好一个换行；如果片段本身含有三个反引号，就用更长的围栏，好让它完整渲染。什么都不选时，复制整个文件。状态栏会说明复制了多少行、用了哪个标记。

5. **说明它在哪儿。**同样的选择，`编辑 ▸ 复制为带链接的 Markdown`（或者右键）。粘贴出来的是同一个代码块，后面跟着 `[src/app/app.ts#L3-L12](https://github.com/you/repo/blob/main/src/app/app.ts#L3-L12)` — 用的是你检出的那个分支（分离的 HEAD 则按提交链接），因为一个从未推送过的本地提交，只会是一个伪装成永久链接的 404。仓库之外的文件、没有 `origin` 的仓库、不是 GitHub 的 origin，或者存在未保存的改动：状态栏会拒绝，什么都不复制。

6. **截一张图。**`工具 ▸ 复制编辑器截图` 会把编辑区当前选中的标签页 — 工具栏、边栏、代码、侧栏，不含 IDE 的外框 — 以二倍图的形式放到剪贴板上；直接粘贴进聊天或幻灯片即可。即使焦点在导航器里，它截的也是你正在看的那个标签页；编辑区什么都没打开时，它会明说，而不是复制一张空白。`工具 ▸ 保存编辑器截图…` 把同样的画面保存为以文档命名的 PNG（`app.ts-<stamp>.png`），而 `工具 ▸ 保存截图…` 保存整个 IDE 窗口（`nmox-studio-<stamp>.png`，默认放在“图片”文件夹）。因为 IDE 是自己绘制自己的，所以不需要授予任何屏幕录制权限，画面里没有桌面，也没什么需要裁剪。

7. **贴出目录树。**`工具 ▸ 将项目树复制为 Markdown`。所指向项目的结构会变成 README 里常见的那种用框线字符画的围栏树：目录在前；`node_modules/ …` 及其同类重型目录只写名字、从不进入；过深或过大的树会被截断，剩余部分计数说明而不是悄悄丢掉；IDE 自己的 `.nmox*.json` 文件被排除在外，因为它们属于产品，而不属于项目。

8. **下台。**再点一次 `视图 ▸ 演示模式`。编辑器、浏览器、Output 和每个终端都会原样回到之前的状态；把 `视图 ▸ 显示按键` 关掉，胶囊就消失了。

## 你刚学到了什么

- **演示是一种状态，而不是一项设置。**演示模式是实时的，从不持久化 — 重启就回到平常 — 而且它是整个产品共享的一个状态，由编辑器来切换，任何窗口都可以跟随。
- **叠加层刻意做得很窄。**显示按键只回显组合键和功能键；你输入的内容永远不会显示出来。
- **无法为自己担保的复制，什么都不复制。**复制为带链接的 Markdown 会在状态栏上拒绝每一个它无法核实的环节 — 没有 origin、不是 GitHub、缓冲区未保存 — 而不是粘贴出一个说谎的链接。
- **每次分享都有边界、都是纯粹的。**目录树从不跟随符号链接，从不进入重型目录，列出的数量有上限并对其余部分计数；编辑器截图就是一张图片，仅此而已。
