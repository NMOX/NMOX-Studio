אולפן הפרויקטים הוא המקום שבו פרויקטים נולדים ומנוהלים: תבניות, עץ קבצים של הפלטפורמה, עורך ל‑package.json והגדרות מוכנות לראק — ובנוסף **הרצה / בנייה / בדיקה / ניקוי** המובנים ב‑IDE, שעובדים בלי שתצטרכו אי פעם לפתוח מסוף.

![אולפן הפרויקטים במעגן השמאלי — עץ הקבצים של הפלטפורמה וסרגל הכלים של הפרויקט, עם ראק המשימות פתוח לצידו](../images/tabs/project-studio.png)

## פתיחה

הלשונית **אולפן הפרויקטים**, שמעוגנת ליד שולחן העבודה, או `קובץ ◂ פרויקט חדש…`.

## צעדים

1. **צרו שלד לפרויקט.** `קובץ ◂ פרויקט חדש…` ← בחרו תבנית (Angular, ‏Vue, ‏Vanilla JS, ‏Elixir/Phoenix, ‏PHP LEMP ועוד). בחרו מיקום (ברירת המחדל היא `~/NMOX`) וסיימו. הפרויקט נפתח והראק מכוון אליו.

2. **עיינו בעץ.** עץ הקבצים הוא עץ פלטפורמה אמיתי — סמלים נכונים לכל סוג קובץ, סימון ענף git ‏`[branch]` על השורש, והתפריט המלא Open/Cut/Copy/Delete/Rename/Tools/Properties. תיקיות כבדות (`node_modules`, ‎`.git`, ‏`dist`) מוצגות בלי צאצאים, כך שגם מאגר ענק נשאר מהיר.

3. **הריצו — בלי מסוף.** השתמשו ב**הרצה** של ה‑IDE (או לחצו על GO של IGNITION בראק). היא מזהה את מנהל החבילות שלכם מקובץ הנעילה של הפרויקט או מהקיבוע של corepack, ומריצה את הפקודה הנכונה; הפלט זורם אל הראק. **בנייה**, **בדיקה** ו**ניקוי** עובדים באותה דרך.

4. **ערכו את package.json.** העורך המובנה מאפשר עריכה מובנית של סקריפטים ותלויות.

5. **טענו הגדרה מוכנה.** תפריט ההגדרות המוכנות מחווט ראק מוכן לתהליך עבודה — משמר זמינות, שער השילוח, ווב מודרני, מסלולי מונוריפו, ספסל Web3 ועוד — כך שלא צריך לבנות את ה‑patch ביד.

## מה למדתם

- פרויקטים חדשים מזוהים לפי כל אחד מ‑60 שמות מניפסט (package.json, ‏Cargo.toml, ‏go.mod, ‏pom.xml, ‏gleam.toml, …) ועוד ארבעה שמזוהים לפי תבנית (`.csproj`, ‎`.fsproj`, ‎`.sln`, ‎`.nimble`) — אפילו אתר של תגי script בלי מניפסט נפתח כפרויקט STATIC.
- הרצה/בנייה/בדיקה/ניקוי והראק הם **מנגנון אחד**; בפעם הראשונה שהם מריצים קוד של הפרויקט תקבלו בקשת אמון בסביבת העבודה.
