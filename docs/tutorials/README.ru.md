Короткие практические разборы тех систем, которые отличают NMOX Studio
от обычной IDE. Каждый проходится за один присест: откройте окно,
выполните шаги — и вы уже по-настоящему воспользовались возможностью.

Широкий справочник (установка, все меню, все страховочные сети) — в
[Руководстве пользователя](../user-guide.ru.md). Полный список приборов —
в [devices.md](../devices.md).

> **О сочетаниях клавиш.** На macOS студии живут в семействе `⌥⌘`
> (Option-Command) — `⌥⌘6`–`⌥⌘9`, `⌥⌘5`, `⌥⌘0`, — потому что простые
> сочетания `⇧⌘` заняты платформой. В Linux и Windows модификатор —
> `Alt+`; меню (Окно ▸ …) работают в любом случае.

При первом запуске открыты три вкладки — «Добро пожаловать», «Стойка
задач» и «Браузер», — а рядом пристыкованы «Студия проекта», «Рабочее
место» и «Обозреватель NPM». Любое другое окно — в одном сочетании
клавиш, и все они перечислены в столбце ИНСТРУМЕНТЫ страницы приветствия.
