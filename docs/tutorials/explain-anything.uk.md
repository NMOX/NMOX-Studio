KVASIR починався як прилад стійки, що пояснює невдалі запуски. Тепер він
дістає до чотирьох місць — стійки, редактора, Студії API та Студії баз
даних, — і кожне його обличчя дотримується тих самих трьох законів: **ви
бачите рівно те, що покине вашу машину, перш ніж щось її покине**, **кожна
поверхня здобуває власну згоду** («так» для помилок збірки ніколи не
дозволяє надсилати код чи SQL) і **таємниці не можуть поїхати разом за
побудовою** (розкриття збирає студія, що володіє даними: облікові
заголовки відкинуто, а паролі поза досяжністю).

![KVASIR пояснює справжній невдалий запуск](../images/kvasir-explain.png)

## Перед початком

Один ключ покриває всі чотири обличчя — від постачальника, якого ви оберете:
Claude (Anthropic), ChatGPT (OpenAI) або Gemini (Google). Натисніть **KEY…**
на лицьовій панелі KVASIR, щоб обрати постачальника й зберегти ключ у
в’язці ключів ОС, або експортуйте `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` чи
`GEMINI_API_KEY`. Немає ключа — немає виклику, і кожне обличчя чесно про це каже.

## Чотири обличчя

1. **Невдалий запуск (стійка).** Поставте KVASIR, запустіть щось, що
   падає, натисніть **EXPLAIN**. Що надсилається: команда, код виходу й
   до п’яти вибраних рядків помилки. Повний розбір — в [уроці про
   KVASIR](kvasir.uk.md), разом із кабелем, що без рук пояснює
   невдачу VERITAS.

2. **Ваш код (редактор).** Виділіть код будь-якою мовою →
   клацніть правою кнопкою → **Запитати KVASIR про виділення…** і наберіть запитання.
   Що надсилається: обрізане виділення, назва файлу й мова — більше
   нічого з вашого проєкту. Це обличчя має *власний* затвор згоди, бо
   згода для невдалих запусків прямо обіцяє, що вихідний код ніколи не
   покидає машину.

3. **Відповідь API (Студія API).** Після надсилання натисніть **Пояснити…**.
   Що надсилається: метод, URL із замаскованими значеннями параметрів,
   статус, заголовки з відкинутими й порахованими обліковими даними та
   обрізане тіло. Корисно, щойно з’являється 401 або дивний заголовок CORS.

4. **Помилка бази даних (Студія баз даних).** Під повідомленням про помилку
   інструкції, що впала, з’являється кнопка **Пояснити…**. Що надсилається:
   виконаний SQL — *разом із його літеральними значеннями, і рядок згоди
   це каже*, бо помилка зазвичай саме про літерал, — плюс повідомлення про
   помилку й тип рушія. Ніколи — підключення, пароль чи рядки.

Кожне обличчя відкриває вікно бесіди: питайте далі, і модель
бачить усю історію цього обміну (не більше десяти обмінів, про що сказано
в стенограмі). Вибір **Fast/Deep** (Haiku/Sonnet) запам’ятовується і
фіксується на всю бесіду, тож стенограма ніколи не бреше про те,
хто відповідав.

## Спробуйте за дві хвилини

Студію баз даних показати найшвидше: відкрийте ⌥⌘7, створіть підключення
SQLite, виконайте `SELECT * FROM user;` у базі, де таблиця зветься
`users`, і натисніть **Пояснити…** на помилці. Прочитайте діалог згоди,
перш ніж погодитися, — це обіцянка продукту, в одному реченні.

## Що ви щойно дізналися

- Чотири поверхні, один шов: кожна студія збирає власне розкриття, а
  діалог згоди цитує його дослівно.
- Відмову виконано тихо й повністю — ні вікна, ні виклику.
- Результат належить робочому простору, що його породив: перемикання
  проєктів очищає відповіді й вкладки результатів, тож «Пояснити» ніколи не
  розкриє дані попереднього проєкту.
