NMOX Studio редагує понад 70 мов зі справжнім підсвічуванням синтаксису,
структурою в Навігаторі та інтелектом мовних серверів — і одразу вміє
налагоджувати JavaScript/TypeScript (і браузер) з точками зупину, які
справді зупиняють. У цьому уроці застосунок Node зупиниться на точці зупину.

![Спрацювала точка зупину JavaScript: виконання призупинено, видно стек викликів Node і живі змінні V8](../images/debug-javascript.png)

## Перед початком

Відкрийте (або створіть) невеликий проєкт Node зі скриптом, який можна
запустити, наприклад маршрут Express або простий `node server.js`.

## Кроки

1. **Відкрийте файл із кодом.** Підсвічування, парні дужки, згортання коду
   й позначення входжень вмикаються самі. **Навігатор** показує структуру
   файлу; мовні сервери (встановлюються за підказками
   `Інструменти ▸ Діагностика середовища…`) додають доповнення й діагностику.

2. **Поставте точку зупину.** Клацніть на полі редактора навпроти рядка
   всередині обробника — з’явиться точка зупину.

3. **Налагодьте файл.** Запустіть **Налагодити файл (точки зупину)** (або
   «Налагодити у Chrome (точки зупину)» для сторінки HTML/JS). Одноразовий
   запит «Довіра до робочої області» охороняє запуск; потім вбудований
   адаптер `js-debug` запускає вашу програму.

4. **Дочекайтеся точки зупину.** Пройдіть потрібним шляхом у коді (зробіть
   запит або дайте скрипту дійти до рядка). Виконання **зупиниться** на
   точці зупину — розглядайте змінні, ходіть стеком викликів, крокуйте з
   обходом і з заходом. Для налагодження в браузері відкривається Chrome з
   одноразовим профілем на живій адресі вашого сервера розробки, а точки
   зупину сторінки відображаються назад в IDE.

## Що ви щойно дізналися

- Редактор вважає понад 70 мов повноправними (граматики TextMate +
  CSL + LSP); файли налаштувань (YAML, TOML, Dockerfile, nginx…) теж
  охоплено.
- Налагодження JS/TS вбудоване — мультиплексор сеансів сплющує дочірні
  сеанси js-debug, щоб налагоджувач платформи, який знає лише один сеанс,
  міг ним керувати.
- Кожен запуск налагодження проходить через довіру, а при зупинці його
  вбивають цілим деревом процесів (без сиріт).

## Далі

- **Запустити цільовий тест** запускає один тестовий метод для кожної мови.
- Діагностика з інструментів стійки (eslint/tsc/phpstan) потрапляє у вікно
  платформи «Завдання».
