ראק המשימות הוא הרעיון המזוהה ביותר עם NMOX Studio: כלי הבנייה, הבדיקה וההגשה שלכם פרושים כראק של מכשירי חומרה שמחווטים ביניהם בכבלים. מכשיר מריץ פקודה אמיתית; כבל מעביר אות אמיתי. המדריך הזה בונה patch זעיר — מריצים משהו, ונורית נדלקת כשהוא מסתיים — כדי שהמטפורה תתיישב.

## לפני שמתחילים

פתחו פרויקט (כל פרויקט Node מתאים; `קובץ ◂ פרויקט חדש…` ← "Vanilla JS" אם צריך אחד). פתיחת פרויקט **מכוונת** אליו את הראק, כך שכל מכשיר רץ בתיקייה של הפרויקט הזה.

## צעדים

1. **פתחו את הראק.** לחצו על הלשונית **ראק המשימות** (או `⌘9`). ראק ההתחלה כולל **MONITOR** יחיד — מכשיר הקונסולה שמציג פלט של פקודות ושורות שגיאה.

2. **הוסיפו מריץ.** גררו את **IGNITION** מהפלטה אל המדף. IGNITION הוא מכשיר ה"הרצה" לכל השפות; כשהוא מכוון לפרויקט Node הוא מריץ `npm run dev` (הוא מזהה בעצמו את מנהל החבילות ואת שרשרת הכלים).

3. **חווטו אותו למוניטור.** לחצו על פקד ה**היפוך** כדי לראות את הצד האחורי, ואז לחצו על השקע **OUT** של IGNITION ועל השקע **TAP** של MONITOR — כבל מחבר ביניהם. (גם גרירה בין השקעים עובדת; לחיצה נוחה יותר כשהראק רחב.)

4. **הפעילו.** הפכו חזרה לחזית ולחצו על כפתור ה‑**GO** של IGNITION. הוא מפעיל את התהליך; הפלט זורם אל MONITOR, ונוריות המצב נדלקות. אם הפרויקט עוד לא מהימן, תקבלו קודם בקשת אמון בסביבת העבודה חד־פעמית — זה השומר שמונע ממאגר ששוכפל להריץ את הסקריפטים שלו בלי רשותכם.

5. **שמרו את ה‑patch.** `⌘S` (או הכפתור **שמירת patch**) כותב ‎`.nmoxrack.json` לצד הפרויקט. פתחו את הפרויקט שוב מאוחר יותר, וה‑patch — מכשירים, כבלים, מיקומי חוגות — חוזר בדיוק כפי שהיה.

## מה למדתם

- **מכשירים הם כלים עם לוח קדמי.** חוגות בוחרות אפשרויות, כפתורי GO מריצים, נוריות וצגים מדווחים על מצב — וכל פקד אמיתי (אין חוגות מתות; בדיקת חוזה אוכפת זאת).
- **כבלים מתאמים מסלולים.** OUT ‏←‏ TAP הוא החיבור הפשוט ביותר; שערי מוכנות (`ENABLE`), מחסומי איחוד (`QUORUM`) וכבלי הדק מאפשרים להרכיב צינור שלם שמגיב לעצמו.
- **הכול נשמר.** ה‑patch הוא קובץ שאפשר להכניס למאגר; הראק אפילו מחייה סשן שרץ אחרי קריסה.

## הלאה

- יש 53 מכשירים — עיינו בהם ב‑[devices.md](../devices.md) או בכרטיסי "איך משתמשים" שבפלטה.
- בקשו מ‑[KVASIR](kvasir.he.md) להסביר הרצה שנכשלה.
- ייצאו patch ל‑workflow של GitHub Actions: **ייצוא ה‑CI** של הראק.
