A Bancada é a base do NMOX Studio — um ponto de partida que mostra num só
lugar o projeto atual, os arquivos abertos e recentes, os projetos
conhecidos e as ferramentas que você tem instaladas. É onde você se situa
antes de mergulhar num estúdio.

![A Bancada no painel esquerdo — o projeto atual com os selos da cadeia de ferramentas, arquivos abertos e recentes, projetos e o diretório de ferramentas](../images/tabs/workbench.png)

## Abrir

`⌥⌘0`, ou a aba **Bancada** (aberta por padrão na primeira execução).

## Passos

1. **Veja onde você está.** A coluna **Projeto atual** mostra o projeto
   apontado e seus fatos principais. Tudo o que o rack e os estúdios fazem
   vale para esse projeto.

2. **Pule entre arquivos.** **Arquivos abertos** e **Arquivos recentes**
   estão sempre atualizados — clique para reabrir. A lista de recentes
   sobrevive a reinícios.

3. **Troque de projeto.** A coluna **Projetos** lista tudo o que o NMOX
   Studio conhece. Clique num para apontar para ele — o rack, o explorador
   e a lista de recentes seguem o mesmo projeto.

4. **Confira suas ferramentas.** A coluna **Ferramentas** mostra os
   estúdios e as ferramentas externas ao seu alcance. Para uma sondagem
   profunda de ~60 ferramentas externas, com versões e dicas de
   instalação, rode `Ferramentas ▸ Doutor do ambiente…`.

## O que você aprendeu

- A Bancada é a tela que responde “no que estou trabalhando e o que posso
  fazer com isso”.
- Apontar um projeto aqui é o mesmo apontar que o rack usa — um projeto, um
  contexto, em todo lugar.
