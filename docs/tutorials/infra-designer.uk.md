Конструктор інфраструктури — полотно для хмарної інфраструктури в стилі
Node-RED. Ви перетягуєте вузли (droplet, firewall, записи DNS…), з’єднуєте
їх і розгортаєте в DigitalOcean, Hetzner або Cloudflare — бачачи вартість,
перш ніж щось витратити. Цей урок будує план і проганяє його насухо, тож
жодні гроші не рухаються.

## Як відкрити

`⌥⌘9` або вкладка **Конструктор інфраструктури**.

## Кроки

1. **Поставте сервер.** Перетягніть вузол **Droplet** з палітри на
   полотно. Лист властивостей праворуч дає задати регіон, розмір та
   образ. Оцінка вартості оновлюється, поки ви обираєте.

2. **Додайте firewall.** Перетягніть вузол **Firewall** і з’єднайте його з
   droplet, провівши лінію між їхніми портами. Задайте вхідне правило
   (наприклад, дозволити 22 і 443).

3. **Додайте cloud-init (необов’язково).** У поле `user_data` droplet
   вставте короткий скрипт cloud-init — він виконається при першому завантаженні.

4. **Проженіть розгортання насухо.** Натисніть червону кнопку **РОЗГОРНУТИ**.
   Без хмарного токена все лишається **пробним прогоном**: ви бачите точний
   упорядкований план викликів API (створити firewall, створити droplet,
   приєднати…) і вартість, але нічого не створюється. Журнал розгортання
   показує кожен крок.

5. **Переходьте наживо (коли будете готові).** Додайте токен постачальника в
   `Параметри` (він зберігається у в’язці ключів ОС) — і РОЗГОРНУТИ виконає план
   насправді, передаючи посилання між вузлами (IP droplet потрапляє в запис
   DNS) у міру того, як піднімаються ресурси.

## Що ви щойно дізналися

- Полотно — справжній граф залежностей: планувальник упорядковує виклики API
  і передає ідентифікатори та IP між кроками.
- Руйнівні діалоги (знищення стека чи ресурсу, розгортання) ставлять клавішу
  Enter на **безпечну** кнопку — рефлекторне натискання не видалить платний
  ресурс.
- Живі ресурси можна **синхронізувати** назад і оновлювати, щоб побачити
  розбіжності; план зберігається в `.nmoxinfra.json`.

## Далі

- Копіюйте команду SSH вузла просто з полотна.
- Кілька хмар: те саме полотно керує DO, Hetzner і Cloudflare.
