استوديو قواعد البيانات مجموعة أدوات لـ SQLite، وPostgreSQL، وMySQL/MariaDB،
وMongoDB، وCouchDB — درايفرات جاية معاه، وكونسول عارفة نوع المحرك، وجداول
نتايج تقدروا تعدّلوها في مكانها. الدرس ده بيستخدم SQLite عشان مش محتاجة
سيرفر.

![اتصال SQLite، واستعلام، وصفوف حية في الجدول — وشريط الحالة بيقول السبب الصريح لما الجدول يكون للقراية بس](../images/db-studio.png)

## افتحوه

`⌥⌘7`، أو تبويب **استوديو قواعد البيانات**.

## الخطوات

1. **اعملوا اتصال SQLite.** اضغطوا **إضافة**، واختاروا **SQLite**، وحددوا
   مسار ملف (نافذة اختيار على طريقة الحفظ بتخليكم تعملوا ملف ‎`.db` جديد).
   الاتصال بيظهر في شجرة الاتصالات.

2. **شغّلوا شوية SQL.** في الكونسول اكتبوا وشغّلوا:

   ```sql
   CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT, active BOOLEAN);
   INSERT INTO users (name, active) VALUES ('Ada', 1), ('Bob', 0);
   SELECT * FROM users;
   ```

   كل جملة بياخد جدول نتايج خاص بيه تحت، ومعاه الوقت.

3. **عدّلوا صف في الجدول.** دبل كليك على خانة `name` بتاعة Bob، وغيّروها،
   ودوسوا **تطبيق…**. استوديو قواعد البيانات مبيسمحش بالتعديل جوه الجدول
   غير لما يقدر يبني `UPDATE` آمن لصف واحد (جدول واحد، والمفتاح الأساسي
   موجود) — وبيوريكم الـ SQL بالظبط قبل ما يشتغل، وبعدين بيستعلم تاني
   عشان يعرض الحقيقة. لو صف مينفعش يتعدّل بأمان، بيقولكم ليه.

4. **صدّروا.** كليك يمين على أي جدول ← **تصدير بصيغة CSV / JSON**. تصدير
   CSV بيحيّد حقن المعادلات في الـ spreadsheets لوحده.

5. **اعملوا EXPLAIN لاستعلام.** حددوا `SELECT` ودوسوا **EXPLAIN** عشان
   تشوفوا خطة الاستعلام من المحرك نفسه.

6. **خلّوا KVASIR يشرح فشل.** شغّلوا `SELECT * FROM user;` (خدوا بالكم من
   الغلطة). تحت رسالة الخطأ بيظهر زرار **شرح…**. دوسوه وهيظهر مربع حوار
   موافقة بيسمّي بالظبط اللي هيتبعت — الـ SQL اللي شغّلتوه (بأي قيم ثابتة
   جواه)، ورسالة الخطأ، ونوع المحرك؛ وعمره ما بيبعت الاتصال، ولا كلمة السر،
   ولا أي صفوف. وافقوا، وKVASIR بيشرح الخطأ وبيقترح الحل، في نافذة محادثة
   بتستقبل أسئلة كمان.

## اللي اتعلمتوه

- كلمات السر في سلسلة مفاتيح النظام بس، عمرها ما بتبقى في ‎`.nmoxdb.json`.
- الكونسول عارفة نوع المحرك: SQL لمحركات SQL، وكونسول مستندات JSON لـ
  MongoDB/CouchDB.
- التاريخ والاستعلامات المحفوظة بتتحفظ لكل مشروع؛ وملفات ‎`.env` بتعرض
  اتصالات `DATABASE_URL`/`DB_*` بتاعتها لوحدها.

## بعد كده

- قاعدة بيانات شغالة في Docker؟ استوديو قواعد البيانات بيعرض عليكم اتصال
  ليها — شوفوا [لوحة Docker](docker-panel.ar.md).
