Студия проекта — место, где проекты рождаются и живут: шаблоны, дерево
файлов платформы, редактор package.json и пресеты стойки, — а также
встроенные в IDE **Запуск / Сборка / Тестирование / Очистка**, которые
работают, даже если вы ни разу не откроете терминал.

![Студия проекта в левой панели — дерево файлов платформы и панель инструментов проекта, рядом открыта Стойка задач](../images/tabs/project-studio.png)

## Как открыть

Вкладка **Студия проекта**, пристыкованная рядом с Рабочим местом, или
`Файл ▸ Новый проект…`.

## Шаги

1. **Создайте проект по шаблону.** `Файл ▸ Новый проект…` → выберите
   шаблон (Angular, Vue, Vanilla Web, Elixir/Phoenix, PHP LEMP и другие).
   Укажите расположение (по умолчанию `~/NMOX`) и завершите. Проект
   откроется, и стойка наведётся на него.

2. **Пройдитесь по дереву.** Дерево файлов — настоящее дерево платформы:
   правильные значки типов файлов, отметка ветки git `[branch]` у корня и
   полное меню «Открыть / Вырезать / Копировать / Удалить / Переименовать
   / Сервис / Свойства». Тяжёлые папки (`node_modules`, `.git`, `dist`)
   показываются без содержимого, чтобы огромный репозиторий оставался
   быстрым.

3. **Запустите — без терминала.** Воспользуйтесь командой IDE **Запуск**
   (или нажмите IGNITE у IGNITION в стойке). Она определяет ваш менеджер
   пакетов по файлу блокировки или закреплению corepack в самом проекте и
   выполняет нужную команду; вывод бежит в стойку. **Сборка**,
   **Тестирование** и **Очистка** работают так же.

4. **Отредактируйте package.json.** Встроенный редактор даёт
   структурированную правку скриптов и зависимостей.

5. **Загрузите пресет.** Меню **Пресеты ▾** Стойки задач собирает готовую стойку под
   рабочий процесс — Uptime Watch, Ship Gate, Modern Web, Monorepo Lanes,
   Web3 Bench и другие, — чтобы не коммутировать схему вручную.

## Что вы узнали

- Новые проекты распознаются по любому из 60 имён манифестов
  (package.json, Cargo.toml, go.mod, pom.xml, gleam.toml, …) и ещё
  четырём, найденным по шаблону (`.csproj`, `.fsproj`, `.sln`,
  `.nimble`), — даже сайт на тегах script без манифеста открывается как
  проект STATIC.
- Запуск/Сборка/Тестирование/Очистка и стойка — **один механизм**; когда
  они впервые запускают код проекта, вы увидите запрос «Доверие рабочей
  области».
