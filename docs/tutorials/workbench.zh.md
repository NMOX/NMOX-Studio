工作台是 NMOX Studio 的母港 — 一块启动板，把当前项目、打开的和最近的文件、已知的项目，以及你装好的工具集中在一处。钻进某个工作室之前，先在这里辨清方向。

![停靠在左侧的工作台 — 带工具链标记的当前项目、打开的和最近的文件、项目，以及工具目录](../images/zh/tabs/workbench.png)

## 打开方式

`⌥⌘0`，或者 **工作台** 标签页（首次启动时默认就打开）。

## 步骤

1. **看清自己在哪。**工作台顶部写着瞄准的项目及其关键信息。机架和各工作室做的每件事，都以这个项目为范围。

2. **在文件之间跳转。****打开的文件**和**最近的文件**都是实时的 — 点一下就重新打开。最近列表在重启后依然保留。

3. **切换项目。****项目**区域列出 NMOX Studio 知道的一切。点其中一个就瞄准它 — 机架、资源浏览器和最近列表都跟着同一个项目走。

4. **检查你的工具。****工具**区域显示你够得着的工作室和外部工具。想对约 100 个外部工具做一次深入探测、看版本和安装提示，就运行 `工具 ▸ 环境诊断…`。

## 你刚学到了什么

- 工作台是那一块回答“我在做什么，能拿它做什么”的屏幕。
- 在这里瞄准一个项目，和机架用的是同一次瞄准 — 一个项目，一个上下文，处处一致。
