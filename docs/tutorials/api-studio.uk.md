Студія API — робоче місце для REST у стилі Postman, вбудоване в IDE. Ви
будуєте запити, перевіряєте відповідь твердженнями і — чого немає більше
ніде — кожна відповідь отримує оцінку за вебстандартами заголовків безпеки.

![Живий 200 за 331 мс — і вкладка «Стандарти» оцінює заголовки безпеки відповіді](../images/api-studio.png)

## Як відкрити

`⌥⌘8` або рядок **Студія API** у стовпці ІНСТРУМЕНТИ сторінки вітання.

## Кроки

1. **Зробіть запит.** У конструкторі запиту встановіть метод `GET`
   і URL `https://httpbin.org/json`. Натисніть **Надіслати**. Тіло
   відповіді приходить відформатованим; рядок стану показує код, час і
   розмір. (Некерована відповідь вам не зашкодить — тіла читаються потоком
   з обмеженням 8 МБ.)

2. **Додайте твердження.** На вкладці **Тести** додайте `Status is 200` і
   `Body contains slideshow`. Надішліть знову — кожне твердження покаже зелену
   ✓ або червону ✗ із фактичним значенням.

3. **Прочитайте оцінку безпеки.** Відкрийте вкладку **Стандарти**. Студія API
   оцінює HSTS, CSP, X-Content-Type-Options, захист від clickjacking,
   Referrer-Policy та інше й ставить літерну оцінку — ту перевірку, яку
   веброзробник 2026 року робить на securityheaders.com, тут вбудовано в кожне надсилання.

4. **Скористайтеся змінною.** Створіть середовище з `base =
   https://httpbin.org`, потім задайте URL запиту `{{base}}/get`.
   Перемкніть середовище — і всі запити разом переспрямуються. Якщо в стійці
   працює живий сервер розробки, Студія API навіть запропонує його адресу як `{{baseUrl}}`.

5. **Додайте автентифікацію безпечно.** На вкладці **Auth** оберіть Bearer або Basic і
   введіть токен. Токен **ніколи** не записується в `.nmoxapi.json`, який
   комітять, — він живе у в’язці ключів ОС, прив’язаний до запиту.

6. **Імпортуйте те, що вже маєте.** Кнопка **Імпортувати…** читає вставлену
   команду curl («Copy as cURL» у devtools браузера), файл запитів
   `.http`/`.rest` або специфікацію OpenAPI 3 (JSON чи YAML) — кожне
   перетворюється на справжні запити, а заголовок `Authorization` одразу переходить
   у поле Auth, що зберігається у в’язці ключів, а не потрапляє у
   файл робочого простору. **Копіювати curl** працює навпаки: точна
   команда, яку виконало б «Надіслати», — у вашому буфері обміну.

7. **Спитайте KVASIR про погану відповідь.** Коли надсилання повертає щось не те,
   натисніть **Пояснити…**. Діалог згоди спершу скаже рівно те, що
   покине вашу машину: метод, URL із замаскованими *значеннями* параметрів
   запиту, статус, безпечні заголовки (облікові заголовки вже відкинуто й
   пораховано) та обрізане тіло — і нічого не надсилається, доки ви не
   погодитеся. Відмовтеся — і нічого не станеться; погодьтеся — і пояснення
   відкриється як бесіда, у якій можна питати далі.

## Що ви щойно дізналися

- Запити, середовища й твердження зберігаються для кожного проєкту в
  `.nmoxapi.json` (без таємниць).
- Оцінка безпеки перетворює «чи спрацювало» на «чи це безпечно».
- Надсилання можна скасувати (кнопка «Надіслати» стає **Скасувати**), і воно
  ніколи не блокує решту IDE.

## Далі

- Спрямуйте запит на запущений сервер стійки через пропозицію `{{baseUrl}}`.
- Відповідник для баз даних — у [Студії баз даних](db-studio.uk.md).
