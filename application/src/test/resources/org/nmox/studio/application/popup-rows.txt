# The rows a RIGHT-CLICK paints.
#
# The menu bar can be read live: the accessibility API hands back its rows
# by process id. A context menu cannot — a right-click on a Swing-painted
# editor pane is a gesture this automation has never delivered. So every
# popup row was unprovable until v2.145.0 built PopupCensus, which asks the
# platform to BUILD the popup and reads the items it would paint.
#
# Its first run found twenty-three English rows in a Hindi build, and
# corrected two guesses: the fold family paints the bare id here and the
# _menu_text one in the menu bar, and Go to Declaration paints a FOURTH
# spelling again (goto-declaration-trimmed). Where a module holds more than
# one name for one action, every one is written.
#
