# 3.2.0: the Team menu (Menu/Versioning). VersioningMainMenu builds it in
# code from the owning VCS: git's Annotator lists the top-level rows and
# its DynamicMenus fill each submenu, every name an NbBundle lookup
# (GitAction.getName() reads LBL_<SimpleName>_Name). Submenus are their
# own menus here, "Versioning/<name>". Three rows REPLACE a sibling in
# place (Hide Annotations for Show, Unignore for Ignore, Include In
# Commit for Exclude); they are recorded in the same menu, so each takes
# a letter of its own -- stricter than needed, never wrong.
# Versioning/Git is the submenu an UNVERSIONED project shows instead of
# the rows above; its keys also appear in Remote and Repository, so
# each letter has to be free in both. Apply Diff Patch sits in Patches
# (git's PatchesMenu.getPatchAction; the diff module registers it in
# no Menu/Versioning folder), corrected from "Versioning" in 3.2.0.
# Other VCS lists other version control systems by name, and this
# build ships one, so its contents were not walked.
