# action classes -- so no parser can enumerate them. A walk of a
# translated build found them and a grep by VALUE placed them, and this
# file is the record of that walk. It is a ledger, like the platform
# dialog ledger: the population is hand-kept, and every claim in it is
# checked against the assembled cluster by CodeNamedMenuRowsTest, while
# MenuRowsSpeakTest reads it alongside its own rows so the mnemonic laws
# see the whole menu bar at once.
