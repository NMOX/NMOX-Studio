# The VS Code keymap profile's chord table: the one input a person edits.
#
# scripts/generate-vscode-keymap.sh lays these chords over the default
# (NetBeans) profile of the assembled cluster and writes the VS Code profile:
# the Keymaps/VSCode and Editors/**/Keybindings/VSCode regions of the ui
# module's layer, the keybinding files beside it, and displaced.txt here.
# VsCodeKeymapProfileGateTest fails the build when the committed files are not
# what this table and the cluster's default profile produce, and
# VsCodeKeymapResolutionTest resolves every row through the assembled cluster.
#
# One row per VS Code default keybinding:
#
#   scope | macOS | Windows | Linux | target | VS Code command [| mime=action ...]
#
# scope   editor  the chord fires an action of the focused editor's kit
#                 (VS Code: "when": "editorTextFocus"); outside an editor the
#                 chord keeps whatever the default profile gives it
#         global  the chord fires an action from the Actions folder, wherever
#                 the focus is; no editor binding may sit on it
# chords  the platform's notation with EXPLICIT modifiers only: S Shift,
#         C Ctrl, A Alt (Option), M Meta (Cmd). No D and no O: a row says what
#         each OS presses, and the generator works out the portable spelling.
#         A two-stroke chord is two strokes with a space between them.
#         "-" in a column: VS Code binds nothing on that OS.
#         "=" in the Linux column: the same as Windows.
# target  editor rows: the kit action's name. global rows: the action's layer
#         path. "none": this product has no honest equivalent; the chord is
#         VS Code's, so it fires NOTHING here (whatever the default profile had
#         on it is displaced, and displaced.txt says what that was).
# mime=action  (editor rows) a language whose kit answers the chord with its
#         own flavour of the same action.
#
# What a Keymaps shadow cannot say: "only on Windows and Linux". A global row
# is therefore either the same keys on every OS, the Cmd/Ctrl twin (M on
# macOS, C elsewhere), or macOS only (spelled with M, a modifier a PC keyboard
# does not send). A Windows-only global chord is refused by the generator;
# such chords are listed, unbound, in docs/coming-from-vscode.md.
